## Channel details


**Country:** set to where the account owner is based (affects payout/tax later, not reach).

## Settings checklist
1. Create a **Brand Account** channel (not the personal one), so access can be shared later.
2. Verify the phone number (unlocks custom thumbnails and videos over 15 min).
3. Audience: "No, it's not made for kids".
4. Upload defaults: category *Autos & Vehicles* (or *Sports*), language English, comments on.
5. Altered/synthetic content flag: not needed for stylised pixel animation of real events, as long as nothing realistic is faked.
6. Music: only the self-made 8-bit audio, so no copyright claims.
7. Buffer: connect YouTube as a channel to post Shorts (vertical MP4, max 3 min) from the repo's raw URLs.
