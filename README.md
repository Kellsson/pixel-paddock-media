# pixel-paddock-media

Media and tools for **The Pixel Paddock** (@the.pixel.paddock), an English-language F1 news account in pixel style.

| Folder | Contents |
|---|---|
| `brand/` | Logo / profile picture, story-highlight covers, "Start here" post, account setup, logo source code. Colours, fonts and rules are in [brand/README.md](brand/README.md). |
| `toolkit/` | Python render code for carousels (1080x1350) and results reels (1080x1920), with fonts and track outlines. See [toolkit/README.md](toolkit/README.md). |
| `posts/` | Published carousels (`YYYY-MM-DD_slug/`), served to Buffer via raw.githubusercontent URLs. |
| `reels/` | Published results reels (`YYYY-MM-DD_session/reel.mp4`). |
| `shorts/` | Historic race recap shorts (map replay) plus their engine. See [shorts/README.md](shorts/README.md). |

Raw URL pattern: `https://raw.githubusercontent.com/Kellsson/pixel-paddock-media/main/<path>`
